# 쓱싹 (SsukSsak) — 안드로이드 저장공간 정리 앱

폰의 사진·동영상을 폰 안에서 분석해서 흔들린 사진, 비슷한 사진, 스크린샷, 어두운 사진, 큰 동영상을 찾아주고, 휴지통(복원 가능)이나 백업 폴더로 안전하게 정리합니다.

- 요구 사양: **Android 11 (API 30) 이상**
- 외부 라이브러리 없음(안드로이드 기본 API만 사용), 분석은 전부 기기 안에서 처리
- 구조: `MainActivity.java`(파일 접근·분석·삭제) + `assets/index.html`(화면, WebView)

## APK 받는 법 (GitHub Actions가 대신 빌드해요)

1. GitHub에서 **새 저장소**를 만듭니다. (Public이면 폰 브라우저에서 바로 내려받을 수 있어요. Private이면 GitHub 로그인이 필요해요.)
2. 이 폴더의 **모든 파일을 저장소에 올립니다.**
   - ⚠️ `.github` 폴더는 이름이 `.`으로 시작하는 숨김 폴더라 드래그 업로드에서 빠지기 쉬워요.
   - 빠졌다면 GitHub 웹에서 *Add file → Create new file*로 `.github/workflows/build-apk.yml`을 만들고 이 폴더의 같은 파일 내용을 붙여넣으세요.
   - Codespaces나 PC가 있다면 `git add . && git commit -m init && git push`가 가장 확실해요.
3. 저장소의 **Actions** 탭에서 *Build APK*가 자동으로 돌아갑니다 (처음 3~5분).
   - 안 돌면 *Build APK → Run workflow*를 누르세요.
4. 끝나면 저장소 오른쪽 **Releases → 쓱싹 최신 빌드**에서 `ssuksak.apk`를 폰으로 내려받습니다.
   (Actions 실행 화면 아래 *Artifacts*의 `ssuksak-apk`로도 받을 수 있어요.)
5. 설치할 때 *출처를 알 수 없는 앱 허용*을 켜고, Play 보호 경고가 뜨면 *그래도 설치*를 누릅니다. (직접 서명한 디버그 빌드라 나오는 정상 경고예요.)
6. 첫 실행에서 **사진·동영상 접근을 허용**하면 스캔이 시작됩니다.

## 알아둘 점

- **휴지통 = 안드로이드 시스템 휴지통**입니다(갤러리 앱의 휴지통과 같음, 30일 보관). 휴지통에 있는 동안은 저장공간이 늘지 않아요. 앱이 정리 직후 "지금 영구 삭제"를 물어보고, 휴지통 탭의 *비우기*로도 용량을 확보할 수 있어요.
- 삭제·복원할 때마다 **안드로이드 시스템 확인창**이 한 번 떠요. 앱이 마음대로 지울 수 없게 하는 OS의 안전장치예요. (300개 단위로 묶어서 물어봐요.)
- **백업**은 사용자가 고른 폴더로 복사 → 크기 검증 → 통과한 파일만 휴지통으로 옮깁니다. 안드로이드 규칙상 `Download` 폴더나 저장소 맨 위는 고를 수 없으니 새 폴더(예: `쓱싹백업`)를 만들어 선택하세요. SD카드·USB도 선택할 수 있어요.
- 처음 스캔은 사진 수에 따라 몇 분 걸리고, 이후에는 새 사진만 분석합니다.
- 인터넷 권한은 WebView 초기화용으로만 선언되어 있고, 코드가 `ssuk.local` 이외의 모든 요청을 차단합니다. 사진은 어디로도 전송되지 않아요.

## 구조

```
app/src/main/
├─ java/com/ssuksak/app/MainActivity.java   MediaStore 스캔, 썸네일 분석(흔들림·밝기·dHash),
│                                           시스템 휴지통/복원/영구삭제, SAF 백업, 분석 캐시
├─ assets/index.html                        화면 (카드, 선택 그리드, 대화, 휴지통, 설정)
└─ res/, AndroidManifest.xml
.github/workflows/build-apk.yml             push하면 APK 빌드 → Releases 업로드
```
